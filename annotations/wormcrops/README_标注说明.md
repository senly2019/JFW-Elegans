# worm_crops 人工标注说明（新标注者盲标协议）

## 目的
验证三类姿态定义（笔直 / Ω / 正弦）在另一个公开数据集（不同显微镜、亮视野紧裁剪图）上是否同样成立。你的判断将与机器规则判定独立比对，因此**标注前和标注过程中不得查看本目录下的 key.csv、simulated_labels.csv 或任何机器判定结果**。

## 环境
在 Windows 本机（PyCharm 项目 `worm_5class_pipeline` 目录下）运行：

```
python human_label_gui_v3.py -b annotation_wc/batch.csv -i annotation_wc/images -o annotation_wc/labels_R1.csv --zoom 7 --min-sec 1.5
```

- 共 300 张，顺序已打乱；每张强制至少 1.5 秒
- 第二位标注者把 `-o` 改为 `labels_R2.csv` 重新标一遍（不要参考第一人的结果）

## 按键
| 键 | 类别 | 判据 |
|---|---|---|
| 1 | STR 笔直 | 整体近直线，无明显弯曲段 |
| 2 | OMG Ω型 | 恰好一个深弯（Ω 形），位置不限 |
| 3 | SIN 正弦 | 两个及以上波浪 |
| 0 | BAD 图像不可用 | 看不到虫体 / 明显两条虫 / 骨架断裂无法判读 |
| 9 | AMB 拿不准 | 在两类之间犹豫且无法决定（少用，尽量逼自己选 1/2/3） |
| u | 改判当前张；n/空格 下一张；p 上一张；+/- 缩放 |

界面顶部有每类示例图（来自主数据，判据相同）。

## 判读要点
- 这批图是紧裁剪亮视野图（43–126 px），虫体可能较小，用 +/- 放大再看
- 图里若出现两条虫 → 选 0（BAD）
- Ω 与正弦的界线：数"深弯"的个数——1 个 = OMG，2 个及以上 = SIN

## 标完后
把 labels_R1.csv（和 labels_R2.csv）发回，由分析脚本与规则判定比对（人–规则 κ、人–人 κ），结果写入论文跨数据集验证部分。key.csv 仅分析时使用。
